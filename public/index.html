02 · How it works

One POST. Pay per call. No accounts.

  1. 1

    Your agent sends context

    A chat message, wallet activity or a transaction, as JSON to one of the /api/mood/* endpoints.

  2. 2

    It pays with x402

    The first response is 402 with a PAYMENT-REQUIRED header. The agent signs a USDT0 payment on X Layer and retries with PAYMENT-SIGNATURE.

  3. 3

    It gets the mood and the next move

    Valence, arousal, intensity and one of 8 mood labels, plus a ritual or role-aware advice like "don't push the upsell".

⚡ energized 🙂 content 🌿 peaceful 🔥 activated 🌫️ neutral ⚠️ agitated 🌧️ subdued 🪨 deflated

04 · Integrate

Drop it into any agent.

Use any x402 client to handle the 402 → pay → retry loop. Or start with the free demo, no payment needed.

// x402-enabled fetch handles 402 → sign → retry for you
const res = await fetch('/api/mood/oracle', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ text: userMessage, agentRole: 'trader' }),
});
const { mood, action } = await res.json();
if (action.intensity === 'zero') return; // don't pitch right now
import requests

r = requests.post('/api/mood/demo', json={
    'text': "Can't sleep, lost money again",
})
print(r.json()['label'])  # e.g. "subdued"
# 1) Free demo
curl -X POST /api/mood/demo \
  -H "Content-Type: application/json" \
  -d '{"text":"Quiet morning, feeling good"}'

# 2) Paid: first call returns 402 + PAYMENT-REQUIRED (base64 JSON, amount "3000" = 0.003 USDT0)
curl -i -X POST /api/mood/read \
  -H "Content-Type: application/json" -d '{"text":"hello"}'

# 3) Retry with the signed payment
curl -X POST /api/mood/read \
  -H "Content-Type: application/json" \
  -H "PAYMENT-SIGNATURE: <base64 signed payment>" \
  -d '{"text":"hello"}'
